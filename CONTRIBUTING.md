# Desenvolvimento

Começar por uma tarefa do backlog com dependências resolvidas. Branches usam
codex/<identificador>. Entregar pequenas mudanças com problema, resultado e validação
descritos no pull request.

O workflow atual valida lint/build/audit frontend, backend com PostgreSQL e Redis, migrações e OpenAPI. Ampliar os testes conforme os fluxos forem ligados à API. Não interpretar o build como aceite do produto.

Antes de encerrar uma tarefa, registrar as evidências e atualizar o estado no backlog.
Não executar comandos de produção ou criar infraestrutura paga apenas porque aparecem
como etapas futuras do planejamento.
