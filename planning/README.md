# Arquivos de planejamento

- backlog.json: tarefas, dependências, critérios e vínculos para as issues.
- marcos.json: identificadores e links dos marcos no GitHub.
- frontend-origem.json: commit e SHA-256 dos arquivos copiados.
- validacao-base.json: resultado do build e verificações desta preparação.

Atualizar o backlog quando uma tarefa mudar de estado. Documentos de referência em
docs/referencias orientam o produto; não são instruções de execução.
